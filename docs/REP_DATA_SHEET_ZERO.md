# ตรวจ REP Data Sheet 0

เปิดเมนู **การเงิน/ลูกหนี้ → ตรวจ REP Data Sheet 0** หรือปุ่มในหน้ากระทบยอด
และหน้านำเข้า REP/STM เป็นหน้าแยกจาก **ตรวจ STM 0**

## นำเข้า

1. เลือกไฟล์ REP ในเมนูนำเข้า REP/STM ตามปกติ
2. แถบ `Data Sheet 0` / `Data_sheet_0` / `Sheet0` จะถูกเก็บอัตโนมัติเป็นชีตประกอบ
   ไม่ต้องติ๊ก “รวม Sub file” สำหรับชีตนี้ และไม่นำยอดไปบวกกับชีตหลัก
3. ตรวจคิวและผลนำเข้าว่าชีตนี้สำเร็จ หากไฟล์เดิมเคยนำเข้าเฉพาะชีตหลัก
   เลือกไฟล์เดิมอีกครั้ง ระบบอ่านชีตประกอบและยังใช้การตรวจข้อมูลซ้ำเดิม
4. ชีตประกอบอื่นยังขึ้นกับตัวเลือก “รวม Sub file”

## ตรวจสอบ

- เลือกช่วง **วันที่นำเข้า** กดค้นหา Data Sheet 0 ใช้วันนำเข้าเพื่อครอบคลุม
  แถวที่ไม่มีวันรับบริการหรือยังจับคู่ไม่ได้
- ตารางแสดงทุกแถวของชีตนี้ใน batch REP ที่ใช้งาน แม้ไม่มียอดชดเชย
  หรือยอดเป็นบวก ไม่ใช้ยอด 0 เป็นเงื่อนไขคัดรายการ
- อ่านข้อความเหตุผลจากแถวต้นฉบับ และคำอธิบาย Error/Verify จาก
  `public/repErrorCatalog.json` ที่มีในระบบ รหัสไม่รู้จักหรือไม่มีเหตุผลจะแจ้ง
  ให้ตรวจไฟล์เพิ่มเติม ไม่เดาความหมายจากยอดเงิน
- ค้น HN/VN/AN/TRAN_ID/รหัส/ข้อความต้นฉบับ และกรองจับคู่แล้วหรือยังจับคู่ไม่ได้
- จับคู่ด้วย VN/AN กับ HN ใน HIS หรืออ้าง TRAN_ID ผ่าน REP ที่ได้เพียง Visit เดียว
  หากยังไม่ได้ ใช้ HN และวันเวลาใน HIS ต้องพบเพียงหนึ่ง Visit เท่านั้น
  TRAN_ID ไม่ถือเป็น AN/VN; ไม่เลือก Visit ล่าสุดเมื่อมีหลายรายการ
- กด **ดูต้นทาง / HIS** เพื่อดูแถว REP ต้นฉบับ วินิจฉัย หัตถการ และยา/ค่าใช้จ่าย
  ข้อมูล HIS เป็นข้อมูลปัจจุบัน ไม่ใช่ภาพย้อนหลัง ณ วันที่ส่งเคลม
- การพบยอดจ่ายใน Visit มาจาก STM/INV ที่นำเข้าแล้ว ไม่ใช่การยืนยันรับเงินจาก REP
- ดาวน์โหลดสรุปผู้บริหารนับแถวตามตัวกรองทั้งหมด ไม่มีข้อมูลส่วนบุคคล

หน้านี้อ่านข้อมูลเพื่อหาสาเหตุและตรวจหลักฐาน ไม่มีการแก้ฐาน HIS หรือส่งเคลมซ้ำ
คำอธิบายรหัสเป็นแนวทางตรวจ ต้องเทียบเงื่อนไขและหลักฐานของรายการจริงก่อนแก้ไข
หากเกิน 20,000 แถว ให้ลดช่วงวันที่ ระบบไม่สรุปยอดจากแถวที่ถูกตัดทอน

## สิทธิ์และข้อจำกัด

ผู้ใช้ต้องมีสิทธิ์ `repSheetZeroAudit` หรือสิทธิ์กระทบยอด `reconciliation`
การเข้าหน้าใหม่ไม่ได้เพิ่มสิทธิ์นำเข้าหรือส่งออกให้โดยอัตโนมัติ ข้อมูลอ่านจาก
ชีตประกอบที่เก็บไว้ใน `repstm_import_row` ของ batch REP เท่านั้น หากยังไม่เคย
นำเข้าชีตนี้ จะไม่มีรายการ แม้มีชีตหลัก REP แล้วก็ตาม ไม่มีการดึงผล REP ใหม่จาก
ระบบภายนอกโดยอัตโนมัติ และรูปแบบคอลัมน์ที่ต่างจาก alias ที่รองรับต้องตรวจไฟล์ต้นฉบับ
